# 🤖 ИПРИС VK Bot

Простой бот ВКонтакте для копицентра ИПРИС.

Бот помогает клиенту:

- выбрать филиал;
- выбрать необходимую услугу;
- получить адрес, телефон и электронную почту нужного филиала;
- быстро оформить заказ.

---

# Возможности

✅ Выбор одного из 4 филиалов

✅ Выбор услуги

✅ Получение контактных данных филиала

✅ Простое и понятное меню

---

# Установка

Установите Python 3.12 или новее.

Затем выполните:

```bash
pip install -r requirements.txt
```

---

# Настройка

Откройте файл

```
config.py
```

и вставьте токен сообщества.

Пример:

```python
TOKEN = "ВАШ_ТОКЕН"
```

---

# Получение токена

1. Откройте сообщество ВКонтакте.
2. Перейдите в **Управление**.
3. Выберите **Работа с API**.
4. Откройте раздел **Ключи доступа**.
5. Создайте новый ключ.
6. Вставьте его в `config.py`.

---

# Запуск

Запустите бота:

```bash
python main.py
```

Если всё настроено правильно, в консоли появится сообщение:

```
Бот запущен...
```

---

# Как работает бот

1. Пользователь пишет в сообщения сообщества.
2. Выбирает филиал.
3. Выбирает услугу.
4. Получает:

- адрес филиала;
- телефон;
- электронную почту.

---

# Изменение филиалов

Все филиалы находятся в файле

```
branches.py
```

Там можно изменить:

- название;
- адрес;
- телефон;
- электронную почту;
- время работы.

---

# Добавление услуг

Список услуг находится в

```
keyboards.py
```

При необходимости можно добавить новые кнопки.
